# План реализации захвата звука Firefox в LibreChat

## Цель

Добавить в поле ввода LibreChat кнопку записи системного звука:

- расположить непосредственно слева от штатной кнопки микрофона;
- в состоянии ожидания показывать иконку `Play`;
- во время записи показывать иконку `Stop`;
- первое нажатие запускает запись;
- второе останавливает её и передаёт файл штатному механизму отправки аудио.

Не использовать `getDisplayMedia`: источником служит PipeWire-устройство `LibreChat_Browser_Capture`.

## 1. Исследование текущей реализации

Найти штатную кнопку, recorder и путь отправки аудио:

```bash
rg -n "MediaRecorder|getUserMedia|audio/(webm|ogg)|microphone|Mic" client packages
```

Зафиксировать:

- где создаётся `MediaRecorder`;
- как выбирается MIME-тип и расширение;
- как `Blob` преобразуется в `File`;
- какой callback загружает или отправляет аудио;
- какие ограничения размера и длительности уже применяются.

Не создавать отдельный backend endpoint.

## 2. Общий recorder

Предпочтительно расширить существующий recorder параметрами источника и constraints, не дублируя загрузку аудио.

Для браузерного источника запросить:

```ts
{
  deviceId: { exact: savedDeviceId },
  echoCancellation: false,
  noiseSuppression: false,
  autoGainControl: false
}
```

MIME-тип выбирать существующей логикой через `MediaRecorder.isTypeSupported()`.

## 3. Выбор устройства

Использовать отдельную настройку, не связанную с обычным микрофоном:

1. Проверить сохранённый `deviceId`.
2. Иначе найти `audioinput`, чья нормализованная метка содержит `librechat_browser_capture`.
3. Если метки недоступны, при первом нажатии запросить обычный `getUserMedia` и попросить выбрать `LibreChat_Browser_Capture`.
4. После выдачи разрешения сохранить `track.getSettings().deviceId`.
5. При `NotFoundError` или `OverconstrainedError` удалить сохранённый ID и повторить настройку.

После остановки записи закрывать tracks, чтобы Firefox не показывал постоянный индикатор доступа.

## 4. Кнопка и состояния

Добавить кнопку в DOM непосредственно перед штатной кнопкой микрофона.

Состояния:

- `idle` — `Play`;
- `requesting` — кнопка временно заблокирована;
- `recording` — `Stop` и активное оформление;
- `finalizing` — блокировка до формирования и передачи файла.

Добавить tooltip и `aria-label` для начала и остановки записи. Не использовать звуковые сигналы: они попадут в запись.

Обычная запись микрофона и запись Firefox не должны запускаться одновременно.

## 5. Завершение записи

После события `MediaRecorder.onstop`:

1. Собрать chunks в `Blob`.
2. Создать `File` с корректным MIME-типом и расширением.
3. Передать его тому же обработчику, который использует штатная запись аудио.
4. Очистить recorder, chunks и MediaStream.
5. Обработать пустую запись, отказ в разрешении и исчезновение устройства.

## 6. Проверки

- Кнопка находится слева от микрофона.
- Иконка меняется `Play → Stop → Play`.
- Уже воспроизводимое YouTube-видео не останавливается.
- Записывается интервал между двумя нажатиями.
- После сохранения разрешения Firefox не показывает повторный выбор источника.
- Запись содержит звук всех окон и вкладок Firefox.
- Штатная кнопка микрофона продолжает работать.
- Ошибки разрешений и отсутствующего PipeWire-источника понятны пользователю.
- При размонтировании компонента активная запись и все tracks корректно завершаются.
